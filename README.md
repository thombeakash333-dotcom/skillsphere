# SkillSphere

Modern responsive online learning and skill-development website.

## Features
- Responsive modern UI
- Course/learning paths
- Skill stack section
- Career paths
- Student resources
- Interactive weekly challenge
- SEO title and meta description
- Open Graph metadata
- Custom favicon

## Run
Open `index.html` in a browser, or use VS Code Live Server.
